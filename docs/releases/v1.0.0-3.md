## English

Ubuntu Gaming Mode **1.0.0-3 GOLD** is the first production release promoted
after clean-install, upgrade, purge/rollback and physical Desktop ↔ Gaming Mode
acceptance testing on Ubuntu 26.04.

UGM adds a SteamOS-style, controller-oriented **Gamescope DRM/KMS Gaming Mode**
session to an existing Ubuntu installation without replacing the normal Ubuntu
desktop.

### NVIDIA reference platform

This release was developed and physically validated on:

- Ubuntu 26.04
- NVIDIA GeForce RTX 2060 6 GB
- NVIDIA proprietary driver 595.91.07
- custom Gamescope `3.16.28-3-g0d07f6e`

Validated in the dedicated DRM/KMS session:

- 4K output
- HDR
- VRR / Adaptive Sync
- Steam Overlay
- gamepad support
- MangoApp / MangoHud
- FSR scaling
- NIS through [Sharp Filter Selector](https://github.com/N3ruk/Sharp-Filter-Selector)
- Desktop ↔ Gaming Mode switching

NVIDIA support in the wider Gamescope ecosystem still carries notable caveats,
so this release intentionally makes a narrow claim: **the RTX 2060 reference
configuration above has passed UGM's physical acceptance tests**. It is not a
claim of universal compatibility with every NVIDIA GPU, driver or display.

### Performance reference

Dragon Ball Z: Kakarot, 1920×1080 internal → 2560×1440 output:

| Scenario | Linear | FSR / NIS |
|---|---:|---:|
| Gamescope nested, SDL | ~96 FPS | ~88–91 FPS |
| Gamescope nested, Wayland | ~101–102 FPS | ~88 FPS |
| Gamescope DRM / UGM | ~120 FPS | ~114–117 FPS |

Observed nested → DRM gain in this test:

- Linear: ~18–25%
- FSR/NIS: ~25–33%

See the full methodology in
[docs/performance/fsr-nis-nested-vs-drm.md](../performance/fsr-nis-nested-vs-drm.md).

### Fixes in 1.0.0-3

- Fixed `/etc/ubuntu-gaming-mode` potentially inheriting restrictive
  permissions in 1.0.0-2.
- Configuration directory is explicitly created as `0755 root:root`.
- `session.conf` remains `0644 root:root`.
- `ubuntu-gaming-mode-doctor` now verifies that the configured UGM user can
  actually read `session.conf`.

### Acceptance status

Validated:

- clean installation;
- upgrade from 1.0.0-2 → 1.0.0-3;
- preservation of the immutable ORIGINAL snapshot;
- purge/rollback to the pre-UGM baseline;
- Desktop → Gaming Mode → Desktop;
- final doctor result: **54 OK / 0 warnings / 0 failures**.

### Custom Gamescope note

The bundled Gamescope binary is a project-specific build adapted during UGM
development for the validated 4K path and the Sharp Filter Selector integration.

The modified Gamescope source tree was later deleted, so the exact patch set is
not reconstructed from memory. The validated binary and its SHA256 remain the
canonical 1.0.0-3 reference. If a future UGM release needs a newer Gamescope,
the necessary integration will be recreated and documented from that new source
base.

## Español

Ubuntu Gaming Mode **1.0.0-3 GOLD** es la primera versión de producción
promovida después de validar instalación limpia, actualización, purge/rollback
y el ciclo físico Desktop ↔ Gaming Mode en Ubuntu 26.04.

UGM añade a una instalación Ubuntu existente una sesión **Gamescope DRM/KMS
Gaming Mode** orientada a mando y con una experiencia similar a SteamOS, sin
sustituir el escritorio normal de Ubuntu.

### Plataforma NVIDIA de referencia

Esta versión se desarrolló y validó físicamente sobre:

- Ubuntu 26.04
- NVIDIA GeForce RTX 2060 de 6 GB
- driver propietario NVIDIA 595.91.07
- Gamescope custom `3.16.28-3-g0d07f6e`

Validado dentro de la sesión DRM/KMS dedicada:

- salida 4K
- HDR
- VRR / Adaptive Sync
- Steam Overlay
- soporte de mando
- MangoApp / MangoHud
- escalado FSR
- NIS mediante [Sharp Filter Selector](https://github.com/N3ruk/Sharp-Filter-Selector)
- cambio Desktop ↔ Gaming Mode

El soporte NVIDIA continúa teniendo limitaciones relevantes en el ecosistema
Gamescope, por lo que la afirmación de esta release es deliberadamente concreta:
**la configuración de referencia RTX 2060 indicada arriba ha superado las
pruebas físicas de aceptación de UGM**. No implica compatibilidad universal con
todas las GPU NVIDIA, drivers o pantallas.

### Referencia de rendimiento

Dragon Ball Z: Kakarot, 1920×1080 interno → 2560×1440 de salida:

| Escenario | Linear | FSR / NIS |
|---|---:|---:|
| Gamescope nested, SDL | ~96 FPS | ~88–91 FPS |
| Gamescope nested, Wayland | ~101–102 FPS | ~88 FPS |
| Gamescope DRM / UGM | ~120 FPS | ~114–117 FPS |

Ganancia nested → DRM observada en esta prueba:

- Linear: ~18–25 %
- FSR/NIS: ~25–33 %

Metodología completa:
[docs/es/rendimiento-fsr-nis-gamescope-nested-vs-drm.md](../es/rendimiento-fsr-nis-gamescope-nested-vs-drm.md).

### Correcciones de 1.0.0-3

- Corregido que `/etc/ubuntu-gaming-mode` pudiera heredar permisos
  restrictivos en 1.0.0-2.
- El directorio de configuración se crea explícitamente como
  `0755 root:root`.
- `session.conf` permanece en `0644 root:root`.
- `ubuntu-gaming-mode-doctor` comprueba ahora que el usuario UGM configurado
  pueda leer realmente `session.conf`.

### Estado de aceptación

Validado:

- instalación limpia;
- actualización 1.0.0-2 → 1.0.0-3;
- preservación del snapshot ORIGINAL inmutable;
- purge/rollback al baseline anterior a UGM;
- Desktop → Gaming Mode → Desktop;
- resultado final del doctor: **54 OK / 0 warnings / 0 fallos**.

### Nota sobre el Gamescope custom

El binario Gamescope incluido es una build específica del proyecto adaptada
durante el desarrollo de UGM para la ruta 4K validada y la integración con
Sharp Filter Selector.

El árbol fuente modificado de Gamescope se eliminó posteriormente, por lo que
el conjunto exacto de parches no se reconstruye de memoria. El binario validado
y su SHA256 siguen siendo la referencia canónica de 1.0.0-3. Cuando una futura
versión de UGM necesite actualizar Gamescope, la integración necesaria se
volverá a implementar y documentar desde esa nueva base de código.
